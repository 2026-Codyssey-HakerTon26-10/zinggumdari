## 3. 흐름과 모듈

```
공공데이터 API ─▶ backend.data.dump ─▶ data/raw/
원문(PDF, 웹, API 산문) ─▶ backend.notices.store.register ─▶ backend.compiler.lines(줄 만들기) ─▶ data/notices/
손 조건표 quote ─▶ backend.compiler.resolve_manual ─▶ rules/manual/ 근거 줄 ID
줄 목록 ─▶ backend.compiler.pipeline.compile(자격 구간 → LLM 1회 → 깨진 조건 정리 → 검증기 → 빠짐 검사) ─▶ rules/compiled/
업로드 ─▶ backend.collector.ingest(거부 검사 → 원문 등록 → compile → 업로드 조건표 → 재판정 알림, 캐시와 재생)
덤프와 조건표 ─▶ backend.search.corpus ─▶ index(2-gram BM25) ─▶ rank(구간 정렬) ─▶ service(배지, 정보 갱신 제안)
```

임준현 표시가 없는 것은 임종한이 만들었다. 임준현이 만든 파일에는 임종한이 더한 것만 적는다.

| 모듈 | 하는 일 |
|---|---|
| `backend/data/dump.py`, `sources.py`, `load.py`, `deadline.py` | API 덤프, 원본 응답 읽기, 신청기한 서술을 날짜로(반기 「2026년 상반기」 포함) |
| `backend/notices/store.py` | 원문 등록, 머리와 줄 목록 저장(원자적 쓰기, #58), 근거 줄 조회, 업로드 소유권 |
| `backend/compiler/llm.py` | 네이토 API 호출(임준현). 더한 것: 스트리밍으로 받고 `message_stop`과 허용된 `stop_reason`이 없으면 실패, 전체 시간 상한(#48) |
| `backend/compiler/pipeline.py` | `compile()`(임준현). 더한 것: 깨진 조건을 other로, `sido`를 짧은 이름으로, 근거 없는 조건과 조건 없는 조건표는 내지 않는다(#48, #52) |
| `backend/compiler/lines.py`, `vocab.py` | 줄 만들기(임준현). 더한 것: 주민등록번호 검사(생년월일 꼴, 전각, 줄표, 줄과 칸 나뉨, 외국인등록번호, #48, #61) |
| `backend/compiler/gov24_bulk.py` | 정부24 대량 추출과 원응답으로 다시 조립(검수한 조건표는 덮어쓰지 않는다) |
| `backend/compiler/resolve_manual.py` | 손 조건표 quote를 근거 줄 ID로(임준현). 손 조건표 12개에 돌리는 쪽을 맡았다 |
| `backend/collector/ingest.py` | `/ingest` 본체. URL은 공개 주소만(DNS 재바인딩 차단), 30MB, 리다이렉트 3번, 전체 60초(#58). 캐시는 PDF 해시로 찾고 재생해도 올린 계정 앞으로 새로 남긴다 |
| `backend/search/corpus.py` | 검색 문서. 청약홈과 LH 마감, 청약 특공 세대수와 단계 태그(#39), 트랙 AI 조건표가 덤프 문서를 대신(#55) |
| `backend/search/rank.py` | 관련도, 마감, 지역, 배지, BM25 순 구간 정렬과 같은 이름 묶기(#27, #50) |
| `backend/search/ports.py` | 판정 엔진, 세션, 프로필, 비슷한 가구(`engine.similar.similar_for`) 연결(#47) |

## 4. 다시 만드는 명령

레포 루트에서 실행한다. LLM 키와 모델은 `.env`의 `CODYSSEY_API_KEY`, `CODYSSEY_BASE_URL`, `LLM_MODEL`, `LLM_MODEL_BULK`.

```bash
uv run --project backend python -m backend.data.dump --source gov24
```

```bash
uv run --project backend python -m backend.notices.store <원문 파일> --doc-id <id> --source web --source-url <URL> --title <제목> --fetched-at 2026-11-01
```

```bash
uv run --project backend python -m backend.compiler.resolve_manual rules/manual/*.json
```

```bash
uv run --project backend python -m backend.compiler.run --src <원문 파일> --doc-id <id> --source upload
```

```bash
uv run --project backend python -m backend.compiler.gov24_bulk
```

```bash
uv run --project backend python -m backend.compiler.gov24_bulk --cache-only
```

`--cache-only`는 원응답으로만 다시 조립하므로 LLM을 부르지 않는다. 2026-11-01에 이 명령으로 다시 조립한 결과가 커밋된 `rules/compiled/`, `data/notices/gov24-*`와 바이트 단위로 같았다.

시연 투입 캐시는 `/ingest`에 위 두 PDF(`data/notices/lh-0000061189.pdf`, `data/notices/lh-2015122300020925.pdf`)를 올려 만들었다. 캐시는 PDF 해시로 찾으므로 같은 파일을 올리면 「캐시 재생」이 된다.

## 5. 정한 것과 이유

| 정한 것 | 이유 | PR |
|---|---|---|
| 시험용 채점을 하지 않고 개발용 5개와 표본 50개로만 말한다 | 시험용 손 조건표를 만든 사람이 프롬프트도 고치게 되어 눈가림이 깨졌다 | #43 |
| 대량 추출 결과를 판정, 검색, 숫자에 모두 넣는다 | SPEC §0 성공 기준 5, §5.4(수백 건 1초), §8(「AI 추출·검수 전」 배지) | #48 |
| 근거 없는 조건은 조건표에 넣지 않고 원문 줄을 미반영으로 남긴다 | 근거 줄은 모든 조건에 필수(api.md §1). 다시 뽑으면 프롬프트 버전과 검수를 다시 해야 한다 | #48 |
| 조건 없는 조건표는 내지 않는다 | 판정에서 아무것도 떨어지지 않아 모든 사람에게 확인 필요 카드로 뜬다 | #48 |
| `sido` 값은 프로필과 같은 짧은 이름 | 엔진이 `sido` 조건을 글자 그대로 비교해 서울 프로필이 서울 제도에서 모두 탈락했다 | #52 |
| 개발용 평가 AI 조건표는 `eval/compiled/`에 둔다 | `rules/compiled/`에 두면 손 조건표와 같은 제도가 카드에 두 번 뜬다 | #48 |
| 손 조건표는 사람 조건이 아닌 줄(대상 주택, 절차)도 other로 남긴다 | 카드는 `apply_text`를 쓰지 않아 옮기면 정보가 사라진다. SPEC §19.1에 「신청할 수 있어요」 장면이 없다 | 결정만(코드 변경 없음) |
| 청약은 조문대로 신혼부부, 생애최초, 다자녀 셋으로 나눈다 | 두 제도의 소득 기준과 부동산 가액 대안이 any_of 한 단계로 안 써진다 | #31 |

## 7. 알려진 한계와 남은 일

- AI 조건표 품질: 조건 4,113개 중 자동 검증은 961개(23%)다. 자동 검증을 통과해도 틀린 경우가 있었다(건강보험 「2세 미만」). 검수는 5개뿐이다.
- 대량 추출은 중앙부처와 서울시 소관만 했다. 서울 밖 시도와 시군구(약 3,000건)는 하지 않았다.
- 카드 고르기: 검수 전 AI 조건표가 많아 프리셋 카드가 수백 장이 된다. SPEC §0의 「골라 단계 순으로」는 카드 쪽(이초롱)에 부탁했다(#48 코멘트).
- 판정 쪽 `superseded`(손 조건표가 이김)는 id가 같을 때만 걸러 트랙 AI 조건표에는 걸리지 않는다. 지금 데이터에서는 걸리는 건이 없다(#55 본문).
- 줄 목록 저장(`save_lines`)은 아직 원자적 쓰기가 아니다(#58은 머리와 원문만).
- 청약 공통 조건표 위에 공고문 조건을 덮어쓰는 것(SPEC §10.3)과 노부모부양 손 조건표는 만들지 않았다.
- 1건(강서구 한부모 제도)은 「관내」를 `sido`로 읽었다. 확인 필요로 걸러지고 지역은 `region`이 판정해 결과에는 영향이 없다.
