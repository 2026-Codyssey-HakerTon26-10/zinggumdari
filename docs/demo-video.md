# 시연 영상 대본 (2분, 모바일)

핵심 한 줄: **묻기 전에, 다음 생애 단계와 부모님 것까지 먼저 챙겨 주는 서비스.**
보여줄 순서: 먼저 제안한다 → 다음 단계를 미리 본다 → 근거는 원문이다 → 부모님도 챙긴다 → 삶이 바뀌면 바로 다시 찾는다 → 새 공고도 AI가 읽어 합류한다 → 알림·리포트로 다시 찾아온다.

## 촬영 준비

- 데스크톱 크롬 개발자 도구 기기 모드(iPhone 14 Pro, 393×852)로 배포 사이트를 연다. 공고 파일 업로드가 쉬워서 실제 휴대전화보다 낫다.
- **새 계정**으로 시작한다(기존 계정은 공고 투입·생활 변화 기록이 남아 있다).
- 배포가 최신인지: 「내 징검다리」 맨 위에 「징검다리 브리핑」 카드가 보이면 된다.
- 공고 투입 파일: `data/notices/lh-0000061189.pdf`(안산신길2 신혼희망타운)를 미리 바탕화면에 둔다.
- 화면 숫자(새로 열리는 제도 3개 등)는 그날 조건표 기준이라 조금 다를 수 있다. 자막의 숫자는 녹화 화면에 맞춰 고친다.
- 장면마다 따로 녹화하고 편집에서 잇는다. 기다리는 시간(판정·공고 처리)은 잘라낸다.

```

가입할 때 지금 생활만 골라도 충분해요
묻기 전에, 먼저 챙겨 드려요
다음 생애 단계를 미리 보여드려요
판정 근거는 언제나 공고 원문
부모님 것까지 함께

알림과 리포트로 다시 찾아와요
```

## 나레이션만 (녹음용)

```
결혼, 출산, 부모님의 노후. 필요한 제도는 늘 지나고 나서야 알게 됩니다.
징검다리는 가입할 때 지금의 생활만 알려주면 됩니다. 결혼을 앞둔 지원 씨로 시작해 볼게요.
검색하지 않아도 먼저 찾아옵니다. 지금 신청할 수 있는 제도, 질문 하나면 정리되는 제도, 결혼하면 열릴 제도, 어머니께 필요한 제도까지요.
결혼하면 무엇이 달라질까요. 새로 열리는 제도, 더 이상 해당하지 않는 제도, 그 전에 해둘 혼인신고까지 한 번에 보여줍니다.
AI가 자격을 판정하지 않습니다. 모든 조건은 공고 원문의 한 줄과 연결되어 있고, 그 줄을 바로 보여줍니다.
부모님 것도 함께 챙깁니다. 어머니가 만 65세가 되는 2031년, 기초연금을 비롯한 제도가 열린다는 것까지요.
실제로 결혼하면 버튼 하나만 누르세요. 바로 다시 찾아서 새로 열린 제도를 맨 위에 올려 드립니다.
새 공고가 나오면 AI가 원문을 읽어 조건표로 만들고, 검증기를 거쳐 내 추천에 바로 합류시킵니다.
다음 단계와 마감일은 알림으로, 정리한 내용은 생애주기 리포트 메일로 다시 찾아갑니다.
나의 오늘도, 부모님의 내일도. 징검다리였습니다.
```
