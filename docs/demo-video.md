# 시연 영상 (2분, 모바일)

핵심 한 줄: **묻기 전에, 다음 생애 단계와 부모님 것까지 먼저 챙겨 주는 서비스.**
AI(LLM)는 공고 원문에서 조건을 뽑을 때(원문당 1번)만 쓰고, 판정·제안·알림은 같은 입력이면 같은 결과가 나오는 규칙 코드가 한다. 영상은 이 구조가 화면에서 어떻게 보이는지를 따라간다.

## 완성본

`scripts/demo/`로 자동 촬영했다(393×852 iPhone 크기, 2배 해상도 786×1704, 30fps, 120초). 실제 엔진(조건표 817개, 판정·플래너·공고 투입 캐시 재생)을 DB 없이 띄운 로컬 화면이다.
**대본과 자막은 같은 문장이다.** 자막은 배경 없이 흰 글씨에 검은 테두리로, 말하는 길이만큼 한 줄씩 바뀐다.

| 파일 (레포 밖 `demo-video/`, 커밋 안 함) | 내용 |
|---|---|
| `징검다리_시연_자막포함.mp4` | 대본 자막을 화면에 구운 버전. 이 자막을 보며 녹음해 얹으면 끝 |
| `징검다리_시연_자막없음.mp4` | 편집기에서 자막을 직접 넣을 때 |
| `자막.srt` | 편집기용 자막(대본과 같은 문장, 36줄, 시간 맞춤) |
| `대본.txt` | 녹음용 대본. 장면별 시간과 자막 줄 그대로 |

## 다시 촬영하기

조건표나 화면이 바뀌면 같은 대본으로 다시 찍는다. 크롬, ffmpeg, Node 22 이상이 필요하다(패키지 설치 없음).

```bash
PYTHONPATH=. uv run --project backend python scripts/demo/record_api.py /tmp/zinggum-demo .
```

```bash
cd frontend && NEXT_PUBLIC_API_BASE=http://127.0.0.1:8031 npx next build && NEXT_PUBLIC_API_BASE=http://127.0.0.1:8031 npx next start -p 3031
```

```bash
python3 scripts/demo/make_cues.py 자막.srt && node scripts/demo/record.mjs /tmp/zinggum-rec 1 && python3 scripts/demo/assemble.py /tmp/zinggum-rec demo.mp4
```

- `record_api.py`: DB 없이 실제 엔진을 띄운다. 가입·프리셋·프로필·알림은 메모리, 공고 투입은 넘긴 폴더의 `data/notices` 복사본에만 쓴다.
- `record.mjs`: 헤드리스 크롬을 CDP로 조작해 `scenes.json`의 시간표대로 장면을 진행하고 screencast 프레임을 모은다. 두 번째 인자 `1`이면 `cues.json` 자막을 화면에 굽는다.
- `assemble.py`: 가변 간격 프레임을 30fps MP4로 만든다.
- `make_cues.py`: `scenes.json`의 대본을 자막 줄(`cues.json`)로 나눠 장면 시간에 글자 수만큼 배분하고 SRT를 쓴다.
- 대본(= 자막) 문구는 `scripts/demo/scenes.json` 한 곳에서 고친다.
